# AM12 File IO and Dictionaries

Canonical source repository: `Python-Level-3`

This project consolidates the legacy `AM12-File-IO-and-Dictionaries` and `AM12-File-IO-and-Dictionaries-Starter` folders into the common course wrapper layout.

## Structure

- `starter/` contains the complete learner brief, unchanged input.txt and incomplete
  parsing/loading/display helpers. Its initial Run prints a reminder.
- `solution/` contains the separate checked, import-safe reference. Both paths trim
  surrounding whitespace, retain string values and use last-value-wins duplicates.

Malformed-record and empty-value policies are explicit. This is a file-reading
assignment, not an invented output-writing project.
