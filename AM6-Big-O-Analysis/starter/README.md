# AM6 Big O Analysis starter

Goal: classify ten mathematical expressions and justify each growth bound.
This is a mathematical worksheet, not a Python implementation task.
Read or download this README; no IDE import is needed.

## Model and walkthrough

Assume n is a positive integer growing without bound. For two-variable problems,
n and m grow independently and are at least 1. The symbol ^ means a mathematical
power here, not Python's XOR operator. log_2 denotes a base-2 logarithm.
The prompts describe growth of an expression representing work, not how long
Python takes to evaluate that expression. A Theta bound gives a tight class;
use the corresponding O bound when recording a Big-O answer.

Attempt one prompt, identify its dominant work, write the classification and
reason, then explain it aloud or in a short note. Do not review the separate
reference until after the attempt. P8 through P10 are challenge-level prompts
within this same analysis project, not separate projects.
