# AM9 Bubble Sort starter

Build a bubble sort implementation for a list of numbers.

## Required Behavior

- Write one function that sorts a list in place using bubble sort.
- Write an improved version that stops early if a full pass makes no swaps.
- Write a helper that returns a sorted copy and leaves the original list unchanged.
- Test with a list that includes duplicates and at least one value already in the correct position.

## Reflection

- Identify which loop controls the number of passes.
- Identify which loop compares neighboring values.
- Explain why bubble sort is still inefficient for long random lists even with the early-exit optimization.
