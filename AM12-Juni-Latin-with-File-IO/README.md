# AM12 Juni Latin with File IO

Canonical source repository: `Python-Level-3`

This project consolidates the legacy `AM12-Juni-Latin-with-File-IO` and `AM12-Juni-Latin-with-File-IO-Starter` folders into the common course wrapper layout.

## Structure

- `starter/` contains the complete learner brief, unchanged original input files,
  five incomplete core helpers and a separate optional punctuation helper.
- `solution/` contains the checked, import-safe reference with explicit case,
  whitespace and file-alias policies. Default execution runs only the core path.

The original first-character-to-end-plus-ay rule and translate name are preserved.
The extension repairs the old quoted example without making punctuation compulsory
or substituting general Pig Latin rules. Reference answers remain outside the starter.
