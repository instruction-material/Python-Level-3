# AM3 Python Fundamentals Problem Set

Canonical source repository: `Python-Level-3`

This project consolidates the legacy `AM3-Python-Fundamentals-Problem-Set` and `AM3-Python-Fundamentals-Problem-Set-Starter` folders into the common course wrapper layout.

## Structure

- `starter/` contains the starter/template snapshot.
- `solution/` contains the solution/reference snapshot.

## Reviewed assignment contract

The complete learner brief is in [starter/README.md](starter/README.md).
Its main.py contains deliberately incomplete callable exercises; initial Run
prints a reminder. [solution/main.py](solution/main.py) contains separate,
import-safe references and direct-run demonstrations. Original source filenames
and preexisting function names are preserved.

Read and attempt the assignment before reviewing completed answers. Run the
repository's verify-course-source.sh for the native regression evidence. This
pack's tests do not certify unrelated legacy source or the whole course audit.
