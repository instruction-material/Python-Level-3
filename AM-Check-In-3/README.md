# AM Check In 3

Canonical source repository: `Python-Level-3`

This project consolidates the legacy `AM-Check-In-3` and `AM-Check-In-3-Starter` folders into the common course wrapper layout.

## Structure

- `starter/` contains the starter/template snapshot.
- `solution/` contains the solution/reference snapshot.

## Verified review workflow

Read `starter/README.md` for the complete assignment, domains, predictions and
self-checks. Coding TODOs remain intentionally incomplete; any supplied tracing
or optimization body is explicitly problem input, not an answer. Initial starter
Run prints an exercise reminder. Reference imports are quiet, with demonstrations
or file writes only during explicit direct execution. Keep completed references
separate from learner work. Original folders, filenames and source assets remain.

Run `bash verify-course-source.sh` from the repository root for the native
reference/starter regressions. A nonempty file count is not correctness proof.
